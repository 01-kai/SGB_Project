# Synthetic Governance Benchmark — Execution Runbook

## 1. Purpose

This runbook defines the reproducible execution order for the Synthetic
Governance Benchmark project.

The operational simulation is framework-independent. DBL, DMM, and ISF
evaluate the same organization states, exchange events, shocks, and recovery
trajectories.

Version 0.3.0 applies exchange outcomes before one recovery update per organization,
uses event-time endpoint maturity for threshold analysis, and selects thresholds by
balanced accuracy by default. Outputs generated by earlier dynamics must not be mixed
with version 0.3.0 results.
